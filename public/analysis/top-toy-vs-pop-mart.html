01 · 品牌定位

定位分野：一个做IP 信仰，一个做品类宽度

PM"创造潮流，传递美好"垂直 IP 运营商
  • 定位：以 IP 孵化与运营为核心的潮流文化娱乐公司，围绕艺术家挖掘 → IP 孵化 → 消费者触达 → 潮玩文化推广 → 产业投资五大领域构建全产业链平台（来源：公司官网）。
  • 逻辑：先有 IP，后有产品。产品线围绕自有 IP 纵向深挖（盲盒、毛绒、MEGA、乐园、影视）。
  • 稀缺性来源：隐藏款概率机制 + 限量 + 艺术家签名，人为制造供给稀缺。
TT"全品类潮玩集合品牌"横向集合零售商
  • 定位：以 IP 孵化与运营为核心的全品类潮玩集合品牌，构建覆盖IP 开发 → 产品设计 → 供应链管理 → 全渠道销售的一体化平台（来源：招股书）。
  • 逻辑：先有货架，后有 IP。用24 个自有 IP + 42 个授权 IP + 660+ 他牌 IP覆盖尽可能宽的审美光谱。
  • 稀缺性来源：弱化稀缺、强调可得性，靠品类宽度与开店密度取胜。
核心论点

定位差异直接决定了两者后面所有指标的分化：泡泡玛特的窄而深带来 72.1% 的毛利率，TOP TOY 的宽而全带来 87.9% 的增速——前者赚深度的钱，后者赚广度的钱。

注：TOP TOY 早期曾尝试纯自有 IP 路线，后转向全品类集合模式（来源：多家财经媒体对招股书及公司历程的报道）。

PM泡泡玛特：增长在减速，但底盘仍厚2026H1
  • 营收 171.7 亿元，同比 +23.8%（2025 全年为 +184.7%）——增速正常回落。
  • 门店仅净增 46 家（+7.3%），增长主要来自单店与线上，而非铺店。
  • 毛利率 72.1% → 69.7%，会员复购率 55.7% → 51.6%，两项核心指标同步小幅走弱。
  • 中国内地会员从 7,258 万增至 8,244 万，会员贡献销售 92.9%——用户资产仍在增厚。
TTTOP TOY：量在涨，价在跌2026H1
  • 内地门店 GMV +12.7%，但客单价 -5.9%、件单价 -7.0%——增量完全由交易笔数（+20.8%）驱动。
  • 销量从 1,420 万件增至 1,720 万件（+21.1%），呈现明显的以价换量特征。
  • 整体多渠道 GMV 13.32 亿元：内地门店 8.96 亿 + 线上 1.67 亿 + 其他 2.07 亿 + 海外门店 0.62 亿。
  • 合并口径收入 9.85 亿元（+32.7%），Q2 单季 4.70 亿元（+16.9%）——环比增速亦在放缓。
核心论点

两家都在"减速"，但性质不同：泡泡玛特是超高基数上的正常回落（+184.7% → +23.8%），且毛利率仍接近 70%；TOP TOY 则是在扩张期就出现客单价与件单价双降，说明其增长对促销与客流依赖较重，品牌溢价尚未建立。

08 · 供应链

供应链：泡泡玛特自建产能护城河，TOP TOY 承接名创生态红利

PM垂直整合：把产能握在自己手里
  • 产能：已建成 6 大生产基地；印尼、柬埔寨、墨西哥的合作工厂于 2026 年 1 月开始出货。
  • 目的：应对爆款需求激增与关税不确定性，缩短补货周期、分散地缘风险。
  • 短板：存货周转天数 121.6 天（2025 年），爆款退潮后库存压力显著；2025 年末存货 54.73 亿元，较 2024 年末的 15.25 亿元大幅上升。
  • 组织：全球员工超 11,000 人（2025 末），其中近 4,000 名为非中国籍员工。
TT生态协同：站在名创的肩膀上
  • 红利：依托名创优品成熟的供应链、线下选址能力与加盟网络快速起量，五年开出 334 家门店。
  • 成本：关联交易占比高——来自名创优品集团的收入占比从 53.5% 降至 46.6%，前五大客户占比从 76.5% 降至 59.5%，依赖在下降但仍高。
  • 压力：存货从 2023 年 1.28 亿激增至 2025 年 4.61 亿；应收账款从 2.29 亿升至 4.84 亿，规模扩张带来的资金占用快速上升。
  • 韧性：经营性现金流连续三年净流入，2025 年达 4.7 亿元；期末现金及等价物 3.92 亿元。
POP MART · 制造纵深

6 大基地 + 海外三国产能

自有产能带来补货速度与品质一致性优势，这是爆款能否被充分变现的关键基础设施。

存货是潮玩行业的共同考题

泡泡玛特存货周转 121.6 天；TOP TOY 存货三年增长 2.6 倍。一旦爆款退潮或新 IP 未接棒，存货将同时冲击毛利与现金流。

海外门店从个位数增至 39 家（2026 年 3 月），已进入日本、泰国、马来西亚、印尼。目标：五年内在 100 个国家和地区开设 1,000 家门店。

核心论点

海外不是"谁先出海"的问题，而是谁的 IP 能在海外被主动追捧。泡泡玛特海外收入已达 162.7 亿元、占比 43.8%；TOP TOY 海外门店 GMV 半年仅 0.62 亿元，且主要借助名创的海外门店网络。差距不在渠道能力，而在IP 的跨文化穿透力。

数据来源：泡泡玛特 2025 年度业绩公布、光明网业绩会报道（2026-03-27）；TOP TOY 招股书（2026-03-31）、名创优品 2026 年中期业绩公告（2026-08-28）。"五年 100 国 1,000 店"为公开报道中的公司目标表述。

Actionable Insights

五条可执行洞察：从看懂差异到做出选择

1
对投资者：用不同的估值框架看这两家公司

泡泡玛特应按IP 公司估值（看 IP 梯队、毛利率、复购率、海外占比）；TOP TOY 更接近零售公司（看开店速度、单店 GMV、存货周转、关联交易占比）。用同一套 PE/PS 横向对比会系统性地误判两者。

2
对 TOP TOY：唯一的关键战役是自有 IP 占比

授权 IP 51.0% + 他牌 43.3% 的结构，决定了毛利率被刚性锁在 32% 左右。自有 IP 占比从 5.7% 提到20%，才可能把毛利率推向 40% 区间，从而支撑独立估值。这是 IPO 故事能否成立的唯一变量。

3
对泡泡玛特：补上 50–100 亿级的 IP 梯队断层

THE MONSTERS 占 38.1%，第二梯队（SKULLPANDA 35.4 亿、CRYBABY 29.3 亿、MOLLY 29.0 亿、DIMOO 27.8 亿）体量相当。真正的任务不是再造一个 LABUBU，而是把第二梯队整体推到 50 亿以上，把"单点驱动"改造成"梯队驱动"。

4
对渠道：轻资产能换来速度，但换不来控制力

TOP TOY 用合伙人模式三年开出 334 家店，代价是直营零售仅占收入 12.4%、客单价与件单价双双下滑、品控与售后投诉集中。规模扩张到一定阶段后，必须回补直营比例与终端管控，否则品牌溢价永远建不起来。

5
对行业：共同变量是毛绒品类与海外市场

搪胶毛绒份额预计从 2025 年 20.0% 升至 2030 年 41.7%，中国潮玩市场预计从 875 亿增至 3,310 亿（弗若斯特沙利文）。两家在毛绒品类与海外市场上的执行力，将决定未来五年的座次。
