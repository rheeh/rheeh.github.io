01基础框架：MOBA 六层系统模型

MOBA 不是单一玩法，而是六层相互依赖的系统栈：核心循环层 → 操作层 → 英雄层 → 对局层 → 元游戏层 → 生态层。下层决定“能不能玩”，上层决定“能不能留”。《漫威超级战争》的问题在于：它在第 4–6 层（对局/元游戏/生态）做了大量机制创新，却在第 1–2 层（核心循环、操作手感）未达品类及格线——上层设计再花哨，也无法弥补下游准入门槛的缺失。下文四套数值分析，对应 L1–L6 的底层可量化支柱。

02经济系统数值拆解：资源循环与滚雪球

MOBA 的经济系统是一个典型的“产出—消耗—储备”闭环：金币来自补刀/击杀/目标物与被动增长，消耗于装备与消耗品，储备体现为先手装备差。关键在于——经济差具有正反馈复合增长特性：领先一方更易拿下目标物与击杀（含 shutdown 赏金），进一步扩大差距。

03成长与战斗数值模型：经验曲线与攻防公式

3.1　升级节奏：累计经验曲线（建模示例）

设英雄从 1 到 15 级所需累计经验满足 X(n)=C·(n/15)1.6（凸函数，后期每级更“贵”）。经验来自补刀、击杀分摊与目标物，使一局约 16–18 分钟到达 15 级——与移动 MOBA 的典型对局时长自洽。

3.2　战斗公式与有效血量权衡（采用 JD 常见形式 dmg = Atk² / (Atk + Def)）

该公式的核心特征是非线性：攻击力对伤害的贡献略低于线性（分母含 Atk+Def），使“堆攻击”与“堆防御”的边际收益不同——这正是装备定价与属性投放必须精细校准的原因。

一句话结论

《漫威超级战争》的失败，是“品类（社交网络效应主导）— 平台（网易缺熟人关系链）— IP（欧美 IP 打中国市场 + IP 周期低谷）”三元错配。它不是做得不够好，而是在一个由网络效应定义护城河的品类里，选了没有关系链基础设施的战场——前面的每一张数值曲线，都是这条结论的量化证据。
