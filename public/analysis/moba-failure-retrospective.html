有了漫威角色，为什么仍留不住玩家？

从角色吸引力，到操作、匹配和一起玩的朋友。

熟悉的角色可以让人愿意试一局，但下一次是否打开游戏，还取决于操作、匹配，以及朋友是否也在。以《漫威超级战争》为例，这篇笔记关注 IP 吸引力与日常对局体验之间的距离。

这是基于公开材料的产品复盘。外部收入估算、玩家评论和主观评分，都不足以独立证明停服原因。

02MOBA 手游的六层系统模型

MOBA 不是单一玩法，而是六层相互依赖的系统栈。下层决定「能不能玩」，上层决定「能不能留」——这是理解《漫威超级战争》失败的第一把钥匙：它在第 4–6 层（对局层、元游戏层、生态层）做了大量设计，却在第 1–2 层（核心循环、操作手感）未达品类及格线。

03品类结构：高 ARPU、低渗透、强网络效应

MOBA 是手游中最典型的网络效应品类：每一个新用户都同时提升所有老用户的匹配质量，因此用户规模本身就是产品功能的一部分。这解释了为何该品类呈现极端的头部集中。

▣ 结构性判断

2024 年 Q2 全球 MOBA 手游以 1.4% 的下载份额贡献 6.1% 的收入，下载量在所有子品类中排名第 27 位[2]。这一「高 ARPU、低渗透」结构意味着：新入局者争夺的不是增量蓝海，而是存量用户的迁移成本。而 MOBA 用户的迁移成本中，占比最大的一项不是「英雄熟练度」或「充值沉没成本」，而是「我的朋友在哪，我就在哪」。

8 项机制中，7 项的留存贡献 ≤ 2 分。唯一的 3 分项（英雄技能还原）属于IP 内容层而非系统层——也就是说，玩家真正认可的部分，恰恰是「漫威授权」直接带来的，而非团队自研的机制设计。而团队倾注最多设计资源的系统层创新（能源核心、行星吞噬者、多层中立资源），在玩家侧几乎未被感知为选择该产品的理由。

更致命的是：这些创新全部叠加在一个手感与流畅度未达及格线的底座上。巴哈姆特深度评测指出其「打擊感比較低」「畫質跟流暢度亦比不上現有的 Moba Game」[27]；知乎测评称「操作手感一般，并不是很顺手」[8]。按图 1 的模型，这是L2 失分导致的系统性塌方。

5.4　六个值得讨论的可能因素（非因果排序）

  1. 社交关系链缺位（贡献度约 30%）　MOBA 是唯一一个「朋友在哪我在哪」决定生死的品类。网易账号体系无法导入熟人关系，皮肤无法成为社交货币，组队开黑缺少自驱动力。同厂的《决战！平安京》重复了完全相同的失败模式，构成强对照。
  2. 匹配池坍塌与治理失效（约 22%）　用户基数一旦跌破临界值，匹配质量呈非线性恶化：段位错配、挂机、演员、撞车刷分。而产品的举报反馈被玩家形容为「机械式回复」[33]，治理缺位进一步加速流失。
  3. 基础手感未达品类及格线（约 18%）　按 AHP 研究，易用性是 MOBA 交互设计最高权重准则[6]。打击感、流畅度、帧率稳定性三项失分，直接抹平了技能组还原的优势。
  4. 发行窗口与 IP 周期错位（约 12%）　2019 年漫威 IP 国内热度峰值时立项，2021 年 7 月才公测——此时漫威电影进入休整期且因《尚气》引发国内舆论争议，IP 处于低谷[11]。版号不确定性导致的宣发热度消耗，是典型的行业性风险。
  5. 全球化缺席（约 10%）　漫威是美国 IP，主场在欧美，但产品始终未真正进入欧美市场，只在东南亚与日韩试水。海外玩家直言「漫威是美国 IP，西方没有这样的游戏是一个失败的操作」[29]。
  6. 商业化的自我矛盾（约 8%）　「无皮肤属性加成」提升了口碑却压缩了付费点；「照搬王者商店模式」又没能复制其社交放大效应。结果是：口碑未能转化为收入，收入不足以覆盖授权费 + 运维成本。停服前月流水据行业观察仍有数百万人民币[34]——它不是赚不到钱，是赚的不够覆盖成本结构。

◆ 核心论断

《漫威超级战争》的根本错误，不是做得不够好，而是「品类–平台–IP」三者选错了组合。

它在由社交网络效应主导的品类（手游 MOBA）里，选择了一个网易不具备关系链基础设施的战场，使用一个主场在欧美、在中国认知度高但情感黏性弱的授权 IP，并在IP 周期低谷时进入已被头部产品锁死的市场。四个变量同时错配，IP 光环只能换来 5 天的免费榜第一，换不来第 6 天的留存。

5IP 主场与市场匹配所选市场为该 IP 的高情感黏性区域✗ 欧美 IP 主攻中国市场高
6发行窗口公测时点距 IP 热度峰值 <12 个月✗ 2019 立项 → 2021 公测高
7成本结构授权费 + 运维成本 < 预期月流水 × 60%✗ 迪士尼授权费高昂高
8赛事与内容规划有明确的分级赛事路径与观赛产品（含观战系统）✗ 观战仅 5 位且限自定义场中
9平衡性治理能力具备数值模型 + 多段位监控 + 双周级迭代节奏△ 更新有但节奏慢、投诉多中
10差异化定位差异化落在用户价值密度最高的层（L2 手感 / L6 社交）✗ 差异化全在 L3–L4中

《漫威超级战争》在 10 项检查中通过 0 项、部分通过 3 项，触发 3 条红线。按此清单，该项目在立项阶段即应被识别为高风险。

7.3　对行业趋势的三点判断

  1. MOBA 的竞争壁垒已从玩法层迁移至生态层。2025 年中国 MOBA 手游市场 417.5 亿元、用户 2.6 亿、渗透率超 35%[9]，增速放缓至 10.2%，品类进入存量成熟期。此阶段新品的胜负手不在机制创新数量，而在社交关系链与赛事内容供给。
  2. IP 强度与 MOBA 变现能力无正相关。宝可梦大集结（2910 万下载，$14.1M）与漫威超级战争（$10M 生命周期）共同证明：IP 能买来首次下载，买不来第二次匹配。IP 在 MOBA 中的正确用法是「把 IP 爽点翻译成机制」（如《漫威争锋》的无 CD 飞行），而非「把 IP 名字贴在技能上」。
  3. 下一阶段的关键变量是 AI 对运营效率与体验底线的重塑。《王者荣耀》已落地 AI 断线托管、AI 语音助手、AI 裁判系统（消极比赛识别效率提升 400%）[16]。值得注意的是，AI 断线托管与 AI 裁判恰恰直击本文图 4 下行螺旋的阶段 3、4（匹配池与治理）——头部产品正在用技术手段加固后来者最难翻越的护城河。

08还有哪些问题没有答案

  • 权重主观性　表 4 的八维权重为分析者依据引证证据赋值，未经过专家德尔菲法或多轮 AHP 一致性检验，量级判断可靠但精确分值不宜直接引用。
  • 第三方估算偏差　MAU 数据来自 ActivePlayer.io 估算模型（C 级），2022-07 至 2023-10 存在反向波动，且该数据源在游戏停服后仍显示「未死亡」，更新滞后明显。
  • 收入口径不可比　漫威超级战争的 $10M 为生命周期 IAP，与其他产品的年度收入口径不同；且未包含可能的渠道分成前/后差异。
  • 玩家口碑样本偏差　TapTap 停服后评分（6.5）显著高于上线期（5.7），存在典型的「幸存者怀旧偏差」——留下的评价者多为高情感投入用户。两期数据应分开解读，不可混用。
  • 未覆盖的维度　本地化适配的具体差异、分区域付费点布局、是否有过区域性赛事尝试等，公开信源不足，未作深入分析。
