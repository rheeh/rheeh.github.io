# 插画、潮玩重写与白底整理

## 内容

- 用户提供的 `研究生的一天喜茶风格插画.zip` 中仅含五张 PNG。按原文件中的 01–05 顺序复制，未裁剪、重绘或修改文字。以二进制摘要核对副本与压缩包一致。
- 主页新增三图预览和插画导航；`/illustrations/graduate-day/` 展示全部五图，并可打开原图。作品标题、说明及画面替代文本统一维护在 `src/data/profile.ts`。
- 新写《当潮玩从陈列柜，走到包上》，不沿用旧 WorkBuddy 演示的财务判断。区分产品形态、收入结构与消费者动机；不虚构到店体验、访谈或购买经历。
- 两个旧潮玩 HTML 入口及其静态兼容路由指向 `/reports/pop-mart/`，目录只保留一篇。
