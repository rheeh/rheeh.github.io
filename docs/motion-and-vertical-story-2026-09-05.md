# 开场、板块导航与连续插画

- 入场新增 SVG 手绘线条描画，人物跑入、轻微回弹、对白出现与名字逐字出现；保留重播与减少动态效果支持。
- 固定的板块导航提供原生锚点跳转、滚动高亮和页面进度。滚动监听用 requestAnimationFrame 合并更新，并清理监听与待执行回调；保留正常滚动，不截获滚轮。
- 板块标题增加揭示与下划线展开；卡片继续错峰出现。IntersectionObserver 改为可见即触发，避免连续长图高度超过视窗后永远达不到比例阈值。
- 主页与详情页均以原文件 01–05 顺序竖排全部五张图；移除旋转、单图边框和视觉上的重复说明，详情页文字说明保留给辅助技术。原图不变。

构建、静态路由准备与 ESLint 通过；生成 HTML 确认五图顺序、锚点唯一、板块链接存在。未执行浏览器交互或截图检查。
